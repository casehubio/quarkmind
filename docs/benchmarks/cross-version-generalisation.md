buildings — differentiation depends on Starport timing which is only visible after

weakest dataset at 50%/50%/66%, while ASUS ROG 2020 (baseBuild 82457) generalises 
well at 71%/79%/86%. This suggests v5.0 patch-specific extraction noise, not a 
fundamental model limitation.
